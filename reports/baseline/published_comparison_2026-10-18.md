## Evidence and qualifications

**MMFakeBench.** I rechecked the paper’s text tables. Section 5.1 specifies macro-F1 for four-way classification. Table 2 validation/test rows report GPT-4V Standard 51.0% / 48.8% and MMD-Agent 61.6% / 61.5%; LLaVA-1.6-34B Standard 25.7% and MMD-Agent 49.9% on validation. Appendix Table 6 is a separate binary fake-vs-real evaluation: it reports F1 (not explicitly macro-F1) and separate accuracy, with GPT-4V Standard 72.3% validation / 74.2% test and MMD-Agent 74.0% / 72.8%. Table 3 numbers are omitted because its caption does not identify the metric, and the extracted 61.6 overlaps Table 2 F1. The ICLR conference paper is the cited source; arXiv v1 was submitted 2024-06-13. [ICLR paper](https://proceedings.iclr.cc/paper_files/paper/2025/file/d6c53fe062716387ff0df73cc53de60c-Paper-Conference.pdf).

**MERIT.** The arXiv record says v1 was submitted 2025-10-20 and v2 revised 2026-04-26. Its current title is MERIT; v1 was titled MIRAGE. Section 4 explicitly defines the binary positive class as misinformation, uses GPT-4o-mini, and queries DuckDuckGo; Section 5.1 Table 1 reports validation, while the accompanying note specifies a 5,000-sample stratified test subset. These are binary results, not MMFakeBench’s four-way source classification. [MERIT v2 record and paper](https://arxiv.org/abs/2510.17590v2).

**NewsCLIPpings.** The original ACL-hosted PDF exceeded the web reader’s size limit, so I used the full-text arXiv v2 HTML (revised 2021-09-21). Table 1 gives Merged/Balanced populations: 71,072 train, 7,024 validation, 7,264 test. Table 3 reports all-sample test accuracy; CLIP ViT-B/32 multimodal scores 0.6023 and VisualBERT-VN scores 0.5863. Section 4.1 says both CLIP and VisualBERT are fine-tuned as the classifiers are trained; VisualBERT-VN uses VisualNews pretraining. The paper reports test accuracy for each split. CLIP’s off-the-shelf use is part of dataset construction/filtering, not the reported classifier regime. These are original-paper values, separate from the later ICLR 2025 Table 7 secondary comparison (NewsCLIPpings F1 figures). [Original arXiv v2 HTML](https://arxiv.org/html/2104.05893v2), [ACL Anthology record](https://aclanthology.org/2021.emnlp-main.545/).

**TRUST-VL.** The primary arXiv HTML gives v2 dated 2025-10-30. Section 4 specifies accuracy and macro-F1. Appendix B says the prompt maps each dataset item to binary Real/Fake. Table 2 lists evaluation populations as MMFakeBench 1,000 (No 300 / Yes 700), NewsCLIPpings 7,264 balanced (3,632 / 3,632), and VERITE 400 balanced (200 / 200); it does not name a split, so split identity is left unstated. Table 3 reports TRUST-VL-13B: MMFakeBench 87.30% accuracy / 85.42% macro-F1; NewsCLIPpings 90.35% / 90.35%; VERITE 73.75% / 73.61%. Appendix B describes VERITE here as binary real/fake, unlike official native 1,000-row three-class evaluation. The model is trained in three stages, including full-model fine-tuning on 198K TRUST-Instruct examples, and uses retrieved external evidence. This is non-comparable to the small local samples and the local native three-way VERITE target. [Primary arXiv v2 HTML](https://arxiv.org/html/2509.04448), [ACL Anthology](https://aclanthology.org/2025.emnlp-main.284/), [official repository](https://github.com/YanZehong/TRUST-VL).

**VERITE.** The paper reports 1,000 test items with counts 338 True / 324 OOC / 338 MC. The official repository independently states final `VERITE.csv` has 1,000 rows and 338 true / 338 miscaptioned / 324 out-of-context. The configured local CSV has 1,001 rows: 338 true / 338 miscaptioned / 325 out-of-context. This is one extra OOC-labeled row; no evidence yet identifies a duplicate or version cause. The local six-row campaign sample cannot reconcile the full-population discrepancy. [Paper](https://arxiv.org/abs/2304.14133), [official repository](https://github.com/stevejpapad/image-text-verification).

**Recent search.** The 2026 MM-VeriAgent preprint abstract reports 70.4% multiclass accuracy with Qwen2.5-VL-7B + agent versus 34.3% backbone, but its exact split and evaluation population were not verified. RL training and specialized tools make it unlike local pretrained controls. [arXiv record](https://arxiv.org/abs/2609.30698).
