# Versioning — experiment fork

Series: exp-vX.Y (tags: paper-exp-v2-X.Y). Patch/minor rules mirror the main line's
VERSIONING.md (wording = patch, added verified information = minor), with one addition:
a version bump that introduces probe RESULTS requires the probe artifact path and its
verification status to be named in the CHANGELOG entry. The main line's v1.0 has no
exp- counterpart; the fork never renumbers the main line.
